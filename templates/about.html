Traffic Violations Management System v1.0

📖 نظرة عامة - Overview

نظام متكامل ومتطور لإدارة المخالفات المرورية مع تكامل API لتمييز لوحات السيارات تلقائياً باستخدام تقنية Plate Recognizer. النظام يوفر واجهة عربية سهلة الاستخدام مع إمكانيات متقدمة لإدارة البيانات والتقارير.

A comprehensive traffic violations management system with automatic license plate recognition powered by Plate Recognizer API. The system provides an easy-to-use Arabic interface with advanced data management and reporting capabilities.
