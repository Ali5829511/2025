## 🎯 الهدف

نشر نظام إدارة إسكان أعضاء هيئة التدريس على منصة سحابية تقبل فترة تجريبية مجانية.

Deploy the Faculty Housing Management System to a cloud platform with free trial.

---

## ✨ الخيار الأول: Render.com (الأسهل - موصى به)

### لماذا Render؟
- ✅ **لا يحتاج بطاقة ائتمانية**
- ✅ **90 يوم مجاني لقاعدة البيانات**
- ✅ **نشر تلقائي بنقرة واحدة**
- ✅ **SSL مجاني**
- ✅ **سهل جداً للمبتدئين**

### خطوات النشر (5 دقائق):

#### 1️⃣ إنشاء حساب
1. اذهب إلى: https://render.com
2. انقر "Get Started"
3. سجل باستخدام حساب GitHub

#### 2️⃣ نشر النظام
1. بعد تسجيل الدخول، انقر "New +"
2. اختر "Blueprint"
3. اختر repository: `Ali5829511/2025`
4. انقر "Apply"
5. انتظر 5-10 دقائق للنشر

#### 3️⃣ إعداد قاعدة البيانات
1. بعد اكتمال النشر، افتح "Shell" من لوحة التحكم
2. شغّل الأمر:
```bash
python init_db.py
```

#### 4️⃣ الوصول للنظام
- الرابط: `https://housing-system.onrender.com`
- اسم المستخدم: `admin`
- كلمة المرور: `Admin@2025`

⚠️ **مهم:** غيّر كلمة المرور فوراً!

## 🚂 الخيار الثاني: Railway.app (سريع جداً)

### لماذا Railway؟
- ✅ **$5 رصيد مجاني شهرياً**
- ✅ **واجهة جميلة وسهلة**
- ✅ **نشر في ثوانٍ**
- ✅ **لا timeout للتطبيق**

### خطوات النشر (3 دقائق):

#### 1️⃣ إنشاء حساب
1. اذهب إلى: https://railway.app
2. سجل باستخدام GitHub

#### 2️⃣ نشر التطبيق
1. انقر "New Project"
2. اختر "Deploy from GitHub repo"
3. اختر `Ali5829511/2025`
4. انتظر البناء

#### 3️⃣ إضافة قاعدة البيانات
1. في المشروع، انقر "New"
2. اختر "Database" → "PostgreSQL"
3. انتظر إنشاء القاعدة

#### 4️⃣ ربط القاعدة بالتطبيق
1. افتح التطبيق
2. في "Variables"، أضف:
   - `DATABASE_URL`: انسخه من PostgreSQL

#### 5️⃣ إعداد البيانات
افتح Terminal وشغّل:
```bash
python init_db.py
```

## 🐳 الخيار الثالث: Docker (محلي أو سحابي)

### لماذا Docker؟
- ✅ **يعمل في أي مكان**
- ✅ **سهل الصيانة**
- ✅ **بيئة معزولة**

### خطوات النشر (5 دقائق):

```bash
# 1. استنساخ المشروع
git clone https://github.com/Ali5829511/2025.git
cd 2025

# 2. تشغيل Docker
docker-compose up -d

# 3. انتظر دقيقة واحدة
# 4. افتح المتصفح: http://localhost
```

## 🆘 المساعدة

### مشاكل شائعة:

#### ❓ التطبيق لا يعمل
**الحل:**
1. تحقق من السجلات (Logs)
2. تأكد من تشغيل `python init_db.py`
3. تحقق من متغيرات البيئة

**الحل:**
1. تأكد من وجود `DATABASE_URL`
2. شغّل `python init_db.py` مرة أخرى

**الحل:**
- اسم المستخدم: `admin`
- كلمة المرور: `Admin@2025`
