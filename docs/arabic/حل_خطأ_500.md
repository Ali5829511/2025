# 🔧 حل خطأ 500 / Fixing Error 500

## المشكلة / Problem
عند فتح صفحة التقرير الشامل تظهر رسالة خطأ 500:
```
يبدو أن شيئا ما حدث خطأ!
500
```

---

## ✅ الحلول السريعة / Quick Solutions

### الحل 1: تثبيت المتطلبات / Install Requirements

**المشكلة:** المكتبات المطلوبة غير مثبتة  
**Problem:** Required libraries not installed

**الحل / Solution:**
```bash
cd /path/to/2025
pip install -r requirements.txt
```

أو تثبيت المكتبات يدوياً / Or install manually:
```bash
pip install Flask==2.3.3 Flask-CORS==4.0.0 Werkzeug==3.0.1
```

---

### الحل 2: إنشاء قاعدة البيانات / Create Database

**المشكلة:** قاعدة البيانات غير موجودة  
**Problem:** Database not created

**الحل / Solution:**
```bash
cd /path/to/2025
python3 database.py
```

يجب أن ترى هذه الرسالة / You should see:
```
✅ Database initialized successfully
```

---

### الحل 3: إعادة تشغيل الخادم / Restart Server

**المشكلة:** الخادم لم يعد تحميل التغييرات  
**Problem:** Server didn't reload changes

**الحل / Solution:**
```bash
# أوقف الخادم بـ Ctrl+C
# Stop server with Ctrl+C

# أعد التشغيل
# Restart
python3 server.py
```

## 🧪 اختبار النظام / Test System

### 1. تحقق من تثبيت Python
```bash
python3 --version
# يجب أن تكون 3.8 أو أحدث
# Should be 3.8 or newer
```

### 2. تحقق من المكتبات
```bash
pip3 list | grep -E "Flask|Werkzeug"
# يجب أن ترى:
# Flask       2.3.3
# Flask-CORS  4.0.0
# Werkzeug    3.0.1
```

### 3. تحقق من قاعدة البيانات
```bash
ls -lh housing.db
# يجب أن يظهر الملف
# File should exist
```

### 4. اختبر الخادم
```bash
# شغل الخادم
python3 server.py

# في نافذة أخرى، اختبر:
curl http://localhost:5000/api/health
# يجب أن يرجع: {"status": "healthy", ...}
```

### 5. اختبر صفحة التقرير
```bash
curl -I http://localhost:5000/system_validation_report.html
# يجب أن يرجع: HTTP/1.1 200 OK
```

## 📋 الخطوات الكاملة من البداية / Complete Steps

إذا كنت تبدأ من الصفر / If starting from scratch:

```bash

# 2. أنشئ بيئة افتراضية (اختياري)

# 4. أنشئ قاعدة البيانات

python3 server.py

# 6. افتح المتصفح
```

## 🔍 أخطاء شائعة أخرى / Other Common Errors

### خطأ: "No module named 'flask'"
```bash
# الحل:
pip install Flask==2.3.3
```

### خطأ: "unable to open database file"
```bash
# الحل:
python3 database.py
```

### خطأ: "Address already in use"
```bash
# المنفذ 5000 مستخدم، استخدم منفذ آخر:
PORT=8080 python3 server.py
```

### خطأ: "Permission denied"
```bash
# على Linux/Mac، أعط صلاحيات التنفيذ:
chmod +x run.sh
```
