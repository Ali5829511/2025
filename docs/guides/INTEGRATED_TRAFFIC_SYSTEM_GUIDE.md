# Integrated Traffic Management System - Comprehensive User Guide

## 📋 نظرة عامة / Overview

نظام مرور متكامل وشامل يجمع بين إدارة المركبات، المخالفات المرورية، الحوادث، الرخص، والتعرف التلقائي على لوحات السيارات باستخدام الذكاء الاصطناعي.

An integrated and comprehensive traffic management system combining vehicle management, traffic violations, accidents, licenses, and automatic license plate recognition using AI.

### 2. قاعدة بيانات السيارات والمخالفات / Vehicle & Violations Database
**الملف:** `vehicle_violations_database.html`
**🌟 الميزة الرئيسية الجديدة**

#### الميزات:
- 📷 **التعرف التلقائي على اللوحات** باستخدام Plate Recognizer API
- 🗄️ قاعدة بيانات شاملة للمركبات
- 📊 تتبع المخالفات لكل مركبة
- 🔁 تحديد المخالفين المتكررين
- 📈 إحصائيات وتحليلات متقدمة
- 🔍 بحث متقدم وفلترة

#### كيفية استخدام التعرف على اللوحات:
1. افتح `vehicle_violations_database.html`
2. اسحب صورة اللوحة أو انقر لرفعها
3. انتظر التعرف التلقائي (ثوانٍ معدودة)
4. شاهد النتيجة مع معلومات السيارة
5. سجل مخالفة مباشرة إذا لزم الأمر

#### البحث في قاعدة البيانات:
```
• البحث برقم اللوحة
• البحث باسم المالك
• فلترة حسب حالة المخالفات
• عرض المخالفين المتكررين
```

### 3. إدارة المخالفات المرورية / Traffic Violations Management
**الملف:** `enhanced_traffic_violations_updated.html`

#### أنواع المخالفات:
- وقوف في مكان ممنوع (150 ريال)
- تجاوز السرعة (300 ريال)
- عدم الالتزام بإشارة المرور (500 ريال)
- استخدام الهاتف أثناء القيادة (500 ريال)
- عدم ربط حزام الأمان (150 ريال)
- الوقوف في مواقف ذوي الاحتياجات (500 ريال)
- قطع الإشارة الحمراء (500 ريال)
- القيادة العكسية (300 ريال)

#### خطوات تسجيل مخالفة:
1. اذهب إلى صفحة المخالفات
2. انقر "إضافة مخالفة جديدة"
3. أدخل رقم اللوحة (أو استخدم التعرف التلقائي)
4. اختر نوع المخالفة
5. حدد الموقع والتاريخ
6. الغرامة تُضاف تلقائياً
7. احفظ المخالفة

---

### 4. إدارة الحوادث المرورية / Traffic Accidents Management
**الملف:** `enhanced_traffic_accidents.html`

#### تصنيفات الحوادث:
- **بسيط (Minor):** أضرار مادية بسيطة، بدون إصابات
- **متوسط (Moderate):** أضرار متوسطة، إصابات طفيفة
- **خطير (Severe):** أضرار كبيرة، إصابات خطيرة
- **حرج (Critical):** حوادث كبرى مع وفيات محتملة

#### خطوات تسجيل حادث:
1. اذهب إلى صفحة الحوادث
2. انقر "تسجيل حادث جديد"
3. أدخل موقع الحادث والتاريخ
4. حدد درجة الخطورة
5. أضف معلومات المركبات المتورطة
6. سجل الإصابات والأضرار
7. احفظ البيانات

---

### 5. إدارة السيارات المحجوزة / Immobilized Vehicles
**الملف:** `enhanced_immobilized_cars.html`

#### أنواع الحجز:
- **Boot (كبح):** تركيب جهاز على العجلة
- **Tow (سحب):** نقل السيارة لمركز الحجز

#### الرسوم:
- رسوم السحب: 500 ريال
- رسوم التخزين: 50 ريال/يوم
- الغرامات المستحقة: حسب المخالفات

#### خطوات حجز مركبة:
1. اذهب إلى صفحة السيارات المحجوزة
2. انقر "حجز سيارة جديدة"
3. أدخل رقم اللوحة
4. حدد نوع الحجز والسبب
5. اربط بالمخالفات ذات الصلة
6. النظام يحسب الرسوم تلقائياً
7. احفظ البيانات

#### إجراءات الإفراج:
1. افتح تفاصيل السيارة المحجوزة
2. تأكد من دفع جميع الرسوم
3. انقر "إفراج عن المركبة"
4. سجل تاريخ الإفراج
5. طباعة إيصال الإفراج

## 📊 قاعدة البيانات / Database Schema

### جداول النظام:

#### 1. vehicles - المركبات
```sql
- id: معرف فريد
- plate_number: رقم اللوحة (فريد)
- make: الماركة
- model: الموديل
- year: السنة
- color: اللون
- owner_id: معرف المالك
- vehicle_type: نوع المركبة
- is_active: نشطة/غير نشطة
```

#### 2. traffic_violations - المخالفات المرورية
```sql
- id: معرف فريد
- vehicle_id: معرف المركبة
- plate_number: رقم اللوحة
- violation_type: نوع المخالفة
- violation_date: تاريخ المخالفة
- location: الموقع
- fine_amount: مبلغ الغرامة
- status: الحالة (pending/resolved)
- reported_by: من قام بالتسجيل
```

#### 3. traffic_accidents - الحوادث المرورية
```sql
- id: معرف فريد
- accident_number: رقم الحادث
- accident_date: تاريخ الحادث
- location: الموقع
- severity: الخطورة (minor/moderate/severe/critical)
- vehicles_involved: عدد المركبات المتورطة
- injuries_count: عدد الإصابات
- damage_estimate: تقدير الأضرار
```

#### 4. immobilized_cars - السيارات المحجوزة
```sql
- id: معرف فريد
- vehicle_id: معرف المركبة
- plate_number: رقم اللوحة
- immobilization_type: نوع الحجز (boot/tow)
- immobilized_date: تاريخ الحجز
- outstanding_fines: الغرامات المستحقة
- towing_fee: رسوم السحب
- storage_fee: رسوم التخزين
- total_fees: إجمالي الرسوم
- status: الحالة (immobilized/released)
```

#### 5. driver_licenses - رخص القيادة
```sql
- id: معرف فريد
- license_number: رقم الرخصة
- full_name: الاسم الكامل
- national_id: رقم الهوية
- license_type: نوع الرخصة
- issue_date: تاريخ الإصدار
- expiry_date: تاريخ الانتهاء
- blood_type: فصيلة الدم
- points_balance: رصيد النقاط
- license_status: حالة الرخصة
```

#### 6. vehicle_registrations - استمارات المركبات
```sql
- id: معرف فريد
- registration_number: رقم الاستمارة
- plate_number: رقم اللوحة
- owner_name: اسم المالك
- vehicle_make: الماركة
- vehicle_model: الموديل
- vehicle_year: السنة
- registration_date: تاريخ التسجيل
- expiry_date: تاريخ الانتهاء
- registration_status: حالة الاستمارة
```

#### 7. plate_recognition_log - سجل التعرف على اللوحات
```sql
- id: معرف فريد
- user_id: معرف المستخدم
- plate_number: رقم اللوحة المكتشفة
- confidence: نسبة الدقة
- vehicle_id: معرف المركبة (إن وجدت)
- recognized_at: وقت التعرف
```
