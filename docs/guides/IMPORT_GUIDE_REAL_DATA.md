## 📊 بنية البيانات

### جدول السكان (residents)
```sql
- name: الاسم الكامل
- national_id: رقم الهوية (مُنشأ تلقائياً)
- phone: رقم الجوال
- building_id: معرف المبنى (مرتبط بـ buildings)
- unit_number: رقم الشقة (0 للفلل)
- is_active: حالة السكن (true)
```

### جدول الملصقات (stickers)
```sql
- sticker_number: رقم الملصق
- resident_id: معرف الساكن
- plate_number: رقم اللوحة
- vehicle_type: نوع المركبة
- issue_date: تاريخ الإصدار
- status: الحالة (active)
```

### جدول المواقف (parking_spots)
```sql
- spot_number: رقم الموقف
- parking_area: منطقة الوقوف
- building_id: معرف المبنى
- apartment_id: معرف الشقة (اختياري)
- is_occupied: مشغول/شاغر
```
